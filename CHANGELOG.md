# Changelog

## [1.1.0] — 2026-05-11

### Исправлено

- **Сайт не открывался из России** — убраны ссылки на Google Fonts (заблокированы РКН); шрифт Inter теперь хранится локально внутри бандла (`@fontsource/inter`)

### Добавлено

- **Скрипт `push.sh`** — удобный способ запушить код на GitHub одной командой (`bash push.sh`)
- **Авто-деплой через GitHub Actions** — при каждом пуше в `main` сайт автоматически собирается и загружается на rentrail.ru (нужно добавить секреты `SSH_PRIVATE_KEY`, `VPS_HOST`, `VPS_USER` в настройках GitHub)
- **Экспорт кода на GitHub** — весь проект теперь продублирован на github.com/Alexseibr/rentrail

## [1.0.0] — 2026-05-01

### Добавлено

- **Аутентификация по email + OTP** — вход через одноразовый код на почту (Resend)
- **Platform Admin** — веб-панель для управления компаниями, флотом, арендами, клиентами, ветками, сервисом; ролевой доступ (superAdmin / platformAdmin / …)
- **Staff App** — мобильное приложение для сотрудников (Expo/React Native): активы, аренды, инциденты, наряды, смена
- **Лендинг** — публичная страница rentrail.ru
- **API Server** — Express 5 + PostgreSQL + Drizzle ORM; 30+ таблиц; JWT + RBAC; Zod-валидация
- **Мульти-тенантность** — изоляция данных по `x-company-id` на уровне каждого запроса
- **Машина состояний активов и аренд** — строгие переходы статусов с логированием
- **IoT / GPS** — TCP-сервер для Teltonika FMB/FMC, парсер CODEC 8/12, геозоны
- **Платёжные шлюзы** — ЮKassa, Тинькофф, CloudPayments (холд / захват / отмена / возврат)
- **Push-уведомления** — Expo Push API
- **Платформенный биллинг** — планы, подписки, счета, платежи
- **Белый лейбл, чёрный список, диагностика, аналитика** — инструменты SaaS-оператора
- **Деплой на VPS** — nginx + pm2 на rentrail.ru (Timeweb, Москва)
