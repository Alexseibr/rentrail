# 1. Launch strategy

## 1.1. Recommend phased rollout
Prepare a staged rollout plan:

### Phase 0 — Internal alpha
- own company as tenant #1
- own branches/stations/assets/staff
- internal operational testing
- validate workflows with real data
- no external tenants yet

### Phase 1 — Controlled beta
- 1–3 friendly pilot companies
- limited modules enabled
- close support
- manual monitoring
- fast feedback loop

### Phase 2 — Paid pilot / early access
- 5–10 tenants
- billing enabled selectively
- onboarding template stabilized
- support/documentation improved

### Phase 3 — Public launch
- broader sales/onboarding
- stronger support process
- platform moderation/billing fully active

Document this rollout model clearly.

## 1.2. Non-goals of launch
Define what is intentionally not promised at initial launch:
- not every IoT integration
- not every mobile field workflow
- not every white-label automation
- not massive self-serve scale on day one
