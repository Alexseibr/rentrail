Теперь нужно перейти к проектированию и реализации database layer для новой multi-tenant SaaS-платформы аренды bike / ebike / scooter / escooter.

Стек:
- PostgreSQL
- Drizzle ORM
- TypeScript

Задача: спроектировать и реализовать первую версию schema.ts / table modules / migrations так, чтобы база сразу была пригодна для:
- multi-tenant SaaS
- company -> branch -> station hierarchy
- RBAC
- clients
- assets
- rentals
- blacklist
- audit
- дальнейшего расширения под telemetry, battery, payments integrations, mobile apps

## Важно
Не делай car-based schema.
Центральная сущность — asset.

Нужно заложить правильную tenant model:
- все бизнес-сущности должны быть привязаны минимум к companyId
- где нужно — branchId
- где нужно — stationId
