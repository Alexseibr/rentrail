Теперь нужно реализовать mobile app foundation для новой multi-tenant SaaS-платформы аренды bike / ebike / scooter / escooter.

Считать, что backend foundation уже существует:
- auth / sessions / RBAC / memberships
- companies / branches / stations
- clients
- assets
- rentals
- blacklist
- payments / deposits
- incidents / maintenance
- inquiries / b2b requests / notifications
- devices / batteries / telemetry / geofences / commands foundation
- reports / dashboard endpoints
- public settings / branding / modules

## Цель этапа
Сделать первую рабочую mobile app foundation для сотрудников/операторов компании, а не для публичных клиентов.

Приоритет mobile MVP:
- login
- current user/session
- company switcher
- branch context
- dashboard
- assets list + asset detail
- rentals list + rental detail + key workflow actions
- clients basic lookup
- inquiries list + basic processing
- notifications
- incidents / maintenance basic workflows
- telemetry-aware summary screens later-ready
- practical field UX for operators and managers

Важно:
- не делать сейчас полноценное клиентское consumer app
- mobile app в этой фазе — это operator/staff app
- UI должен быть role-aware, company-aware, branch-aware
- не делать car-specific naming
- foundation должен быть clean и ready для расширения later with QR/photo/camera/push/offline

## Стек
Используй:
- React Native
- Expo
- TypeScript
- Expo Router или React Navigation — выбери clean вариант и объясни
- TanStack Query for server state
- Zustand or Context for auth/app context
- react-hook-form + zod resolver for forms
- secure token storage через Expo SecureStore
- clean API client layer
- UI primitives reusable, без избыточного дизайна
