Нужно начать разработку новой multi-tenant SaaS-платформы для аренды велосипедов, электровелосипедов, самокатов и электросамокатов для доставки и городской мобильности.

Важно: не пытайся сразу сделать весь продукт. Сначала нужно заложить правильный foundation проекта: архитектуру, базовую схему данных, auth, multi-tenant, роли, компании, филиалы, станции, клиентов, транспорт и аренды.

## Цель
Построить с нуля web-first SaaS-платформу, где:
- каждая компания является отдельным tenant
- внутри компании есть филиалы по городам
- внутри филиалов есть станции / точки выдачи / хабы
- есть сотрудники с ролями и доступами
- есть клиенты / курьеры
- есть транспорт: bike, ebike, scooter, escooter
- есть аренды, платежи, депозиты, blacklist, incidents, maintenance
- в будущем будут mobile apps, telemetry, smart lock, battery monitoring, geofence, alarm

## Стек
Используй следующий стек:
- Monorepo на pnpm workspaces
- Backend: Node.js + TypeScript + Express 5
- Database: PostgreSQL
- ORM: Drizzle ORM
- Validation: Zod
- Auth: JWT access + refresh tokens
- Frontend admin/web: React + Vite + TailwindCSS + shadcn/ui
- Object storage: S3-compatible
- Архитектура должна быть модульной и готовой к росту

## Важно
Не делай car-based модель.
Центральная сущность системы — не автомобиль, а asset / transport unit.

Поддерживаемые типы транспорта:
- bike
- ebike
- scooter
- escooter

Сразу проектируй систему как multi-tenant SaaS, а не как single-company app.
